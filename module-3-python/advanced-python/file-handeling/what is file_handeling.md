# what is file_handeling in python ?
  1. file handeling is a process where we can handel a file 
  2. file handeling is used to open a file | closed a file | read a file | write on file | update on file | removed a file etc.

  3. file handeling used some inbuild methods and modes 

      **methods in file handeling**
      1. open() : open a file
      2. close(): close a file 
      3. read() : read a file
      4. write(): write on file
      5. with() : handel automatically closed a file without using close method if used with()
      

      **mode in file handeling**

      1. r: read only
      2. r+: read/write only 
      3. w:write only if file does not exist create a new also
      4. w+: write/read if file dees not exist create a new file
      5. a: append on file create new if not exist
      6. a+: append and read create a new if not exist
