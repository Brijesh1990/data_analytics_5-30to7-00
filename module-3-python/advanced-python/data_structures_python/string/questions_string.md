# String Practice Questions

## 🔹 Basic String Questions
- Write a Python program to count the number of vowels in a string.
- Reverse a string without using slicing (`[::-1]`).
- Check if a string is a palindrome.
- Find the frequency of each character in a string.
- Remove all spaces from a string.

## 🔹 Intermediate String Problems
- Find the first non-repeating character in a string.
- Check if two strings are anagrams.
- Replace all occurrences of a substring with another substring.
- Count the number of words in a string.
- Convert a string to title case without using built-in functions.

## 🔹 String + Data Structures (Lists, Dicts, Sets)
- Store character frequencies using a dictionary.
- Remove duplicate characters from a string using a set.
- Find the most frequent character in a string.
- Group anagrams from a list of strings.
- Find common characters between two strings using sets.

## 🔹 Advanced String Problems
- Implement string compression (e.g., `"aaabb"` → `"a3b2"`).
- Find the longest substring without repeating characters.
- Check if a string contains only digits.
- Implement a function to rotate a string by `k` positions.
- Find all substrings of a string.
