# what is seaborn library in python ?

  1. seaborn is used to create an graph inside of python 
  2. seaborn used python > 3.6.0
  3. seaborn used numpy | pandas | matplotlib for creating graph
  4. seaborn is used to plot data on graph
  5. seaborn is used to data visualisation inside of graph 
  

# how to used seaborn 

  1. pip install seaborn 
  2. pip install matplotlib 
  3. pip install pandas 
  4. pip install numpy
