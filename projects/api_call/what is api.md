# what is api ? 

API means **Application Programming Interface**. An API is a set of rules that allows one application to communicate with another application.


1. api stands for application programming interface 
2. api is used to request a url and get response in web
3. api get data in formate of json 
4. api get response in .json formate 
5. what is json ? 

- json stands for javascript object notation 
- json is array of data 
- json third party api
